# 编辑原则库（给 AI Agent 看）

> 这 6 条是"严肃模式"预设。**默认不启用**——不是每个站都需要这么严肃。
> 安装时（playbook Q3-8）用多选问用户要哪些、要不要自定义；用户选中的 id 写入 `site.json` → `editorial.principles`，自定义口径写入 `editorial.custom`。
> `pipeline/lib/edit.js` 会把选中原则的 prompt 规则注入 LLM prompt；`about` 页的"编辑原则"栏按选中项动态渲染。

## 1. 宁缺毋滥（no-filler）

相关性不够的候选一律舍弃，不为凑满条数降低标准；当天无够格内容则沿用前期版本并明确标注。

## 2. 信源优先（source-first）

优先选择有多家媒体报道的新闻；每条链接原样引用出处，不编造。

## 3. 只陈述，不推断（no-inference）

摘要与分析只写公开报道明确提到的内容，不确定的标注"待确认"。

## 4. 红线（red-lines）

不收以特定个人为主要焦点的新闻；不做操作教程；不做投资建议。

## 5. 头条摘要完整呈现（full-summary）

首页每条头条直接展示完整摘要与一句话点评，不用点进详情页也能读完当天的全部头条；不截断引流，不玩标题游戏。

## 6. 可信度标记（credibility-badges）

「待确认」表示单信源报道、关键信息尚未经多方证实；「多信源」表示有多家独立媒体交叉报道。不确定的我们会明说。
